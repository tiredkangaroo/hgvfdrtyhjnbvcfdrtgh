# hgvfdrtyhjnbvcfdrtgh
a game made for [jumpstart haven](https://jumpstart.hackclub.com/). 

- hit the asteroids and throw them off course from hitting the purple platform.
- you hit the asteroids with the square
- you have 5 lives. you lose one life everytime an asteroid hit the purple platform.
- the asteroid explodes when it goes out of bounds. you get a point every time an asteroid does that.
